# Joint Ventures presentation website

## Goal
Turn the complete 10-page presentation into a polished, single-page website while preserving its exact visual language: white editorial canvas, deep navy and electric blue, bold uppercase typography, pale blue information panels, diagrams, photography, and concise business storytelling.

## Build
- Create a sticky, minimal chapter navigation and a responsive opening section matching the title slide.
- Translate every presentation page into a full-width web section, preserving its headline, argument, examples, diagrams, timelines, and memory lines.
- Recreate the visual diagrams with responsive HTML/CSS and familiar icons rather than flattening the presentation into page screenshots.
- Add subtle reveal and diagram motion while respecting reduced-motion settings.
- Use purpose-made supporting imagery in the same cool, high-contrast corporate photography style.
- Ensure the full experience works cleanly on desktop and mobile, with accessible labels and readable layouts.

## Technical details
- Keep the existing TanStack application structure.
- Define the presentation palette, typography, spacing, shadows, and motion centrally as semantic design tokens.
- Add unique page metadata for “The Hidden Costs of Joint Ventures.”
- Validate the finished page in the live preview at desktop and mobile sizes.
